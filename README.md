# 🎮 CodeAlpha Hangman Game

A modern, interactive **Hangman Game** developed as part of the **CodeAlpha Python Programming Internship**.

The project combines Python game logic with a modern web-based interface to provide an engaging and responsive gaming experience.

## ✨ Features

* 🎯 Classic Hangman gameplay
* 🔤 Predefined word collection
* ❤️ Maximum of 6 incorrect guesses
* ⌨️ Physical keyboard and on-screen keyboard support
* 📊 Game statistics including attempts and wrong guesses
* 🏆 Score and streak tracking
* 🎨 Modern dark gaming-style UI
* ✨ Animated Hangman figure
* 🎉 Win and loss animations
* 🔄 New Game / Play Again functionality
* 📱 Responsive design for different screen sizes
* 🔔 Interactive notifications
* 📖 How to Play section

## 🎮 How to Play

1. Start a new game.
2. A hidden word will appear on the screen.
3. Guess the letters of the hidden word.
4. Each incorrect guess adds another part to the Hangman figure.
5. You can make a maximum of **6 incorrect guesses**.
6. Guess the complete word before all attempts are used to win.
7. Start another round using the **Play Again** button.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/CodeAlpha_HangmanGame.git
```

### 2. Open the project folder

```bash
cd CodeAlpha_HangmanGame
```

### 3. Install the required dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

### 5. Open it in your browser

Visit:

```text
http://127.0.0.1:5000
```
